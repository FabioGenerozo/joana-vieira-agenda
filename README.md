# Joana Vieira — Agenda & Gestão

Protótipo inicial do sistema para manicure e pedicure.

Inclui:
- Dashboard
- Agenda
- Cadastro de clientes
- Controle de presença
- Financeiro básico
- Cadastro de serviços
- Salvamento local no navegador (localStorage)

Próxima etapa sugerida:
1. Validar o layout e os fluxos.
2. Conectar ao Firebase para os dados ficarem sincronizados entre celular/computador.
3. Adicionar histórico detalhado, WhatsApp, lembretes e relatórios.
